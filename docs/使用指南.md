# 墨阅使用指南

这份指南覆盖日常使用：打开保存、阅读与编辑、公式图表、主题、插件、笔记夹、导出与快捷键。更细的插件/主题包开发说明见对应文档。

## 1. 打开与保存

- 新建：侧栏「新建文档」或 `Ctrl+N`。
- 打开：侧栏「打开」或 `Ctrl+O`；也可以把文件直接拖进窗口，或用命令行 `moread 文档.md`。
- 保存：`Ctrl+S`；另存为在「更多 → 另存为」，或 `Ctrl+Shift+S`。
- 自动保存：在「设置」里开启后，停止输入约 1.5 秒自动写回已有文件；新文档仍需先选一次保存位置。
- 最近打开 / 收藏夹：侧栏可直接点开；收藏只记录路径，不复制文件。
- 收藏夹的两个按钮：`收藏当前` 保存正在编辑的文档，`添加路径…` 直接挑选已有文件（可多选，不读取正文）；每行显示文件名与完整路径，同名文件也能区分。
- 外部程序改了同一个文件时，用「更多 → 从磁盘重新载入」。

## 2. 阅读与编辑视图

顶部右侧切换，快捷键 `Ctrl+1 / 2 / 3 / 4`：

| 模式 | 用途 |
| --- | --- |
| 阅读 | 只读预览，适合校对与演示 |
| 分栏 | 左侧源码、右侧预览，滚动同步 |
| 编辑 | 专注源码，带行号与语法高亮 |
| 可视化 | 直接在渲染结果里改标题、列表、表格、公式、图片 |

编辑区支持多标签、未保存标记、撤销/恢复（`Ctrl+Z` / `Ctrl+Y`）与查找（`Ctrl+F`）。可视化模式下也可以用工具栏的撤销/恢复按钮。

侧栏由左上角的墨阅图标开关（`Ctrl+Shift+B` 同样有效）。窄屏只在放不下时把侧栏收成抽屉：≥620px 仍并排显示，更窄时点左上角图标打开、点内容区关闭。手机端格式栏变成几个下拉菜单：标题级别、格式（加粗/斜体/代码/链接/列表/引用等）、颜色、插入、插件，加上撤销、恢复、保存。

侧栏「文档大纲」按标题层级编号：每个有子标题的层级前都有箭头，可单独展开/收起；标题下方还有「展开全部 / 收起全部」，一次展开或收起所有层级。

## 3. 常用编辑操作

- 工具栏：加粗、斜体、删除线、行内代码、链接、公式、引用、列表、任务、表格、颜色、撤销/恢复、保存。
- 「更多格式」（`⋯`）里有有序列表、引用、任务、删除线、公式编辑器。
- 「+」是插入菜单：图片、代码块、行内/块级公式、Mermaid、链接、表格、分割线。
- 颜色：选中文字后用颜色按钮设文字色/高亮；行内代码里的 `#rrggbb` 会自动显示色块。
- 插入图片：桌面用相对路径保存，Android 以 data URL 内嵌（单张上限 300 KB）。

## 4. 公式（KaTeX）

- 行内：`$E = mc^2$`；块级：`$$ ... $$`。
- 公式编辑器：`Ctrl+Shift+M` 或工具栏 Σ，提供符号面板、模板与实时预览。
- 双击预览里的公式可以再次编辑；删除公式会同步改源码。

## 5. Mermaid 图表

在 ```` ```mermaid ```` 代码块里写图，支持流程图、时序图、思维导图等常用语法。

- 预览里双击图表，或点图表标题栏的「编辑」，进入图表编辑器；可视化编辑器支持结构树、节点/连线、布局与配色。
- 标题栏还有「源码 / 复制」：源码会就地展开代码块，复制拿到可粘贴的 mermaid 源码。
- 思维导图与「无子图、无 classDef、无链式连线」的流程图是节点级结构编辑；时序图 / 类图 / 状态图 / 饼图 / 甘特图 / 旅程图 / ER 图等提供逐行结构编辑（每行一条语句，可增删、上移下移），右侧实时预览；复杂语法仍可切到「源码」。
- 可视化模式下，图表、公式、代码块、表格等不可直接输入的区域后面会留出一条可点击的空行，光标可以落在它们之后继续写。
- 第一行可以写 `%% moread:mindmap theme=moss layout=tree direction=TB` 这类注释做单图配色/布局覆盖。

## 6. 表格与代码

- 鼠标移到表格上会出现工具条：上方/下方加行、左侧/右侧加列、删除行列；表头行不会被删掉。
- 代码块自动高亮；「代码块…」可以选语言；预览里代码块带复制按钮。

## 7. 主题与外观

打开「主题工作室」（工具栏画笔或 `Ctrl+Shift+,`）：

- **色彩**：主/副强调色实时生成整套配色；22 个组件颜色可逐项覆盖，也能「从主题色生成」。
- **图标 / 贴纸**：换软件图标，给欢迎页和阅读页加贴纸。
- **主页**：用 Markdown 替换欢迎页，支持图片、公式与链接。
- **页面样式**：导入或粘贴 CSS，实时生效；只影响外观。
- **主题包**：把当前外观存成主题包，可导入、切换、覆盖更新、改名、删除、导出；拖入 `.zip` 或 `.moread-theme.zip` 即可导入。
- **界面**：逐项隐藏工具栏/状态栏等元素。

主题包里的脚本按钮与 CSS 来自外部文件：导入时会确认，脚本第一次运行还会显示内容再确认。

## 8. 插件

「设置 → 插件管理」：

- **安装**：安装 `.zip` 插件包（`plugin.json` 在压缩包根目录，或只套一层文件夹）；再次安装同 id 会提示覆盖，即更新。
- **启用 / 停用 / 卸载**：用户目录安装的插件可卸载；内置插件只能停用。
- **重新扫描**：重新加载入口脚本，改完插件不用重启墨阅。
- **打开插件目录**：直接定位到用户插件目录。
- **格式栏入口**：桌面端每个启用的插件在格式栏有一个自己的图标按钮（图标来自插件的 SVG/PNG 文件），点开只列这个插件的元素、脚本按钮和命令；手机端收成一个「插件」下拉，按插件分组列出全部动作。
- **元素表单**：元素声明了字段时（标题、内容、颜色、样式等），点选后先弹表单，确认后插入 `[name ...]`。
- **脚本按钮**：第一次运行会确认来源与脚本内容；运行后不再占用右下角的浮动按钮区（那里只放你自己在主题工作室里加的按钮）。
- **图标要求**：新安装的插件包必须带图标文件（`icon` 指向 `assets/icon.svg` 等，支持 SVG/PNG/JPEG/WebP），缺少或文件不存在时安装会被拒绝。
- **加载失败**：列表会直接显示原因，终端里也有 `[plugins]` 日志。

插件是可执行本地代码的扩展，只启用可信来源。Android 端暂不支持插件。

## 9. 笔记夹

侧栏「笔记夹」把笔记保存为真实 Markdown 文件：

- 新建笔记 / 新建文件夹，支持嵌套与折叠；文件夹的「⋯」菜单里可以「新建子笔记 / 新建子文件夹」，行尾「⋯」可重命名、分享、删除。
- 笔记用显示名做标签，不进入「最近打开」。
- 可把文件夹按层级导出为 ZIP。
- 桌面文件在 `<用户数据目录>/notes/<id>.md`，Android 在应用私有目录；卸载应用会清掉 Android 的笔记。
- 首次启动时，**介绍、使用指南、插件制作指导、主题包制作指导** 会自动放进笔记夹；删掉后不会再自动出现。

## 10. 导出与分享

- 导出 HTML / PDF / 纯文本：「更多」菜单。
- 分享：桌面把正文复制到剪贴板；Android 走系统分享面板（文件分享带 `.md` 文件名）。
- 导出的 HTML 是静态快照；插件元素会以当前渲染结果导出，插件资源是 `file://` 绝对地址，换机器可能缺图。

## 11. 文件关联与命令行

- 「设置 → 默认打开方式」可把 `.md / .markdown / .mdown` 注册到墨阅（当前用户级别，不需要管理员）。
- Windows 10/11 可能需要在系统设置里再确认一次默认应用。
- 命令行：`moread 文档.md` 打开文件；`moread --import-theme="主题包.zip"` 启动时导入主题包。

## 12. Android 端

- 打开/保存走 SAF；从别处打开的文件多为只读授权，保存失败会引导「另存为」或写入应用私有目录再分享。
- 导出 PDF 走系统打印；图片以 data URL 内嵌；窗口图标、注册表关联、拖拽导入是桌面专属。
- 插件、命令行导入主题包不支持；其余阅读/编辑/主题/笔记能力与桌面一致。

## 14. 常见问题

- **Windows 提示未知发布者**：安装包未签名，点「更多信息 → 仍要运行」。
- **中文乱码**：墨阅按 UTF-8 读写；请让外部程序也以 UTF-8 保存。
- **自动保存没有生效**：新文档先手动保存一次；「设置」里确认自动保存已开启。
- **主题/插件导入失败**：看提示与终端日志；主题包需包含 `theme.json`，插件包需包含 `plugin.json`。
- **脚本按钮不能运行**：首次运行需要确认；被停用的插件不会显示按钮。
