# 墨阅 MoRead · Wiki

墨阅是一款本地优先的 Markdown 阅读与编辑器：文档以纯文本 `.md` 保存，渲染、主题与插件都在本机完成，不上传、不锁定格式。桌面端基于 Electron，Android 端基于 Capacitor，共用同一套渲染层。

MoRead is a local-first Markdown reader and editor. Your documents stay plain `.md` files; rendering, themes and plugins all run locally.
