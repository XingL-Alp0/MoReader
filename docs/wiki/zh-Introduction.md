# 墨阅介绍

> 中文 · [English](en-Introduction)

墨阅（MoRead）是一款本地优先的 Markdown 阅读与编辑器：文档以纯文本 `.md` 保存，渲染、主题、插件都在本机完成，不上传、不锁定格式。桌面端基于 Electron，Android 端基于 Capacitor，两端共用同一套渲染层。

## 为什么是墨阅

- **读得舒服**：纸张质感的排版、代码高亮、表格、脚注、任务列表，公式（KaTeX）与 Mermaid 图表都能直接渲染。
- **写得顺手**：阅读、分栏、编辑、可视化四种模式随时切换；格式栏覆盖常用格式，表格可以点着改。
- **长得像自己**：主题工作室调色、22 个组件颜色、贴纸、自定义主页、页面 CSS；主题包可以导入导出、装很多套随时切换。
- **可以扩展**：插件能给 Markdown 增加自定义元素（比如提示卡、更多分割线），提供脚本按钮，或在「更多」菜单里加导入 / 导出 / 工具命令；插件还能带图片、图标等资源。
- **哪儿都能用**：Windows 桌面版与 Android 版共用同一套文档、主题与插件规则；插件在两端都能用（Android 通过 `.zip` 安装到应用私有目录）。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| Markdown 阅读 / 编辑 | 阅读、分栏、编辑、可视化四种模式 |
| 公式 | 行内 `$E=mc^2$` 与块级公式，内置 LaTeX 符号面板与实时预览 |
| Mermaid 图表 | 流程图、时序图、思维导图等；双击进编辑器，结构树 / 源码两种编辑方式 |
| 表格 | 悬停工具条增删行列，源码与可视化模式都可用 |
| 主题工作室 | 主/副色生成整套配色、22 个组件颜色、图标、贴纸、自定义主页、页面样式、主题包库 |
| 插件 | 自定义元素 + 脚本按钮 + 菜单命令 + 自带资源；`.zip` 安装、启停、卸载、热重载；桌面与 Android 通用 |
| 文件导入 / 导出 | 内置导出 HTML / PDF / 纯文本；示例插件把 Word（`.docx`）导入接进「更多」菜单 |
| 笔记夹 | 笔记与文件夹、无限嵌套、分享、按层级导出 ZIP |
| 文件关联 | 注册为 `.md` 默认打开方式，双击即开（桌面端） |

## 数据与隐私

- 文档是普通 Markdown 文件，墨阅不写入私有格式。
- 设置、主题资源、笔记保存在用户数据目录（Windows 下为 `%APPDATA%\MoRead`；Android 为应用私有目录）。
- 没有遥测，不上传文档内容；外部访问只来自你自己插入的图片链接、主题包图片或插件脚本。
- 插件、主题包里的按钮脚本会在本机执行 JavaScript。**墨阅不做沙箱**：只安装、启用你审查过来源的插件与主题包；脚本按钮第一次运行会显示来源与内容并请求确认。

## 平台

- **Windows**：NSIS 安装包；未做代码签名，首次运行 SmartScreen 可能提示「更多信息 → 仍要运行」。
- **Android**：可侧载 APK；打开/保存走系统文件选择器（SAF），导出 PDF 走系统打印，分享走系统分享面板。插件只能通过「安装插件（.zip）」装到应用私有目录，没有可浏览的插件文件夹。

## 上手三步

1. 打开或新建一篇 `.md` 文档。
2. 用顶部的「阅读 / 分栏 / 编辑 / 可视化」切换工作方式，按 `Ctrl+S` 保存。
3. 想换外观进「主题工作室」，想扩展内容去「设置 → 插件管理」。
