# 墨阅使用指南

> 中文 · [English](en-User-Guide)

覆盖日常使用：安装、打开保存、四种视图、公式图表、主题、插件、笔记夹、导出与快捷键。插件/主题包的开发细节见对应指导：[插件制作指导](zh-Plugin-Authoring)、[主题包制作指导](zh-Theme-Packs)。

## 1. 安装与启动

- **Windows**：运行 NSIS 安装包。安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」。文档不会放进安装目录。
- **Android**：侧载 APK；首次打开可能需要允许「安装未知应用」。
- 设置、主题资源、笔记保存在用户数据目录：Windows 为 `%APPDATA%\MoRead`，Android 为应用私有目录。Android 卸载应用会一并删除笔记与插件。

## 2. 打开与保存

- **新建**：侧栏「新建文档」或 `Ctrl+N`。
- **打开**：侧栏「打开」或 `Ctrl+O`；也可以把文件拖进窗口，或用命令行 `moread 文档.md`。
- **保存**：`Ctrl+S`；另存为在「更多 → 另存为…」或 `Ctrl+Shift+S`。
- **自动保存**：在「设置」开启后，停止输入约 1.5 秒自动写回已有文件；新文档仍需先选一次保存位置。
- **最近打开 / 收藏夹**：侧栏直接点开；收藏只记录路径，不复制文件。
  - 「收藏当前」保存正在编辑的文档；「添加路径…」直接挑选已有文件（可多选，不读取正文）。
  - 每行显示文件名与完整路径，同名文件也能区分。
- 外部程序改了同一个文件时，用「更多 → 从磁盘重新载入」。

## 3. 界面速览

- 顶部标题栏：品牌、窗口标题、主页按钮、主题切换、主题工作室、帮助、设置。
- 标签栏：多标签、未保存圆点、视图切换、「更多」。
- 格式栏：标题级别、加粗/斜体/删除线/行内代码/链接/公式、引用、列表、任务、表格、颜色、撤销/恢复、保存；桌面端还有每个插件自己的图标按钮。
- 侧栏：新建/打开、最近打开、收藏夹、笔记夹、文档大纲。
- 侧栏用左上角墨阅图标开关（`Ctrl+Shift+B`）；窄屏放不下时收成抽屉：≥620px 并排显示，更窄时点图标打开、点内容区关闭。
- 欢迎页：新建、打开、最近阅读，以及插件提供的导入命令（例如「导入 Word 文档…」）。

## 4. 四种视图

顶部右侧切换，快捷键 `Ctrl+1 / 2 / 3 / 4`：

| 模式 | 用途 |
| --- | --- |
| 阅读 | 只读预览，适合校对与演示 |
| 分栏 | 左侧源码、右侧预览，滚动同步 |
| 编辑 | 专注源码，带行号与语法高亮 |
| 可视化 | 直接在渲染结果里改标题、列表、表格、公式、图片 |

编辑区支持多标签、未保存标记、撤销/恢复（`Ctrl+Z` / `Ctrl+Y`）与查找（`Ctrl+F`）。可视化模式也能用工具栏的撤销/恢复按钮。

## 5. 编辑与插入

- 工具栏：加粗、斜体、删除线、行内代码、链接、公式、引用、列表、任务、表格、颜色、撤销/恢复、保存。
- 「更多格式」（`⋯`）里有有序列表、引用、任务、删除线、公式编辑器。
- 「＋」是插入菜单：图片、代码块、行内/块级公式、Mermaid、链接、表格、分割线。
- 颜色：选中文字后用颜色按钮设文字色/高亮；行内代码里的 `#rrggbb` 会自动显示色块。
- 插入图片：桌面用相对路径保存；Android 以 data URL 内嵌（单张上限 300 KB）。

## 6. 公式（KaTeX）

- 行内写 `$E = mc^2$`，块级写 `$$ ... $$`。
- 公式编辑器：`Ctrl+Shift+M` 或工具栏 Σ，提供符号面板、模板与实时预览。
- 双击预览里的公式可以再次编辑；删除公式会同步改源码。

## 7. Mermaid 图表

在 ` ```mermaid ` 代码块里写图，支持流程图、时序图、思维导图等常用语法。

- 预览里双击图表，或点标题栏的「编辑」进入编辑器；可视化编辑器支持结构树、节点/连线、布局与配色。
- 标题栏还有「源码 / 复制」：源码就地展开代码块，复制得到可粘贴的 mermaid 源码。
- 思维导图与「无子图、无 classDef、无链式连线」的流程图是节点级结构编辑；时序图 / 类图 / 状态图 / 饼图 / 甘特图 / 旅程图 / ER 图等提供逐行结构编辑（每行一条语句，可增删、上移下移），右侧实时预览；复杂语法仍可切到「源码」。
- 可视化模式下，图表、公式、代码块、表格等不可直接输入的区域后面会留一条可点击的空行，光标可以落在它们之后继续写。
- 第一行可以写 `%% moread:mindmap theme=moss layout=tree direction=TB` 这类注释做单图配色/布局覆盖。

## 8. 表格与代码

- 鼠标移到表格上会出现工具条：上方/下方加行、左侧/右侧加列、删除行列；表头行不会被删掉。
- 代码块自动高亮；「代码块…」可以选语言；预览里代码块带复制按钮。

## 9. 主题与外观

打开「主题工作室」（工具栏画笔或 `Ctrl+Shift+,`）：

- **色彩**：主/副强调色实时生成整套配色；22 个组件颜色可逐项覆盖，也能「从主题色生成」。
- **图标 / 贴纸**：换软件图标，给欢迎页和阅读页加贴纸。
- **主页**：用 Markdown 替换欢迎页，支持图片、公式与链接。
- **页面样式**：导入或粘贴 CSS，实时生效；只影响外观。
- **主题包**：把当前外观存成主题包，可导入、切换、覆盖更新、改名、删除、导出；拖入 `.zip` 或 `.moread-theme.zip` 即可导入（桌面端）。
- **界面**：逐项隐藏工具栏、状态栏等元素。

主题包里的脚本按钮与 CSS 来自外部文件：导入时会确认，脚本第一次运行还会显示内容再确认。制作方法见 [主题包制作指导](zh-Theme-Packs)。

## 10. 侧栏

- **最近打开**：最多 12 条，点击即开。
- **收藏夹**：记录路径；「收藏当前」与「添加路径…」见 §2。
- **笔记夹**：笔记保存为真实 Markdown 文件。
  - 新建笔记 / 新建文件夹，支持嵌套与折叠；文件夹的「⋯」菜单可「新建子笔记 / 新建子文件夹」，行尾「⋯」可重命名、分享、删除。
  - 笔记用显示名做标签，不进入「最近打开」；文件夹可按层级导出为 ZIP。
  - 桌面文件在 `<用户数据目录>/notes/<id>.md`；Android 在应用私有目录，卸载应用会清掉。
  - 首次启动时，介绍、使用指南、插件制作指导、主题包制作指导会自动放进笔记夹；删掉后不会再自动出现。
- **文档大纲**：按标题层级编号；每级前的箭头可单独展开/收起，标题下方还有「展开全部 / 收起全部」。

## 11. 插件

「设置 → 插件管理」：

- **安装**：安装 `.zip` 插件包（`plugin.json` 在压缩包根目录，或只套一层文件夹）。再次安装同 id 会提示覆盖，即更新。
- **启用 / 停用 / 卸载**：用户安装的插件可卸载；内置插件只能停用。停用/卸载后格式栏图标、菜单命令与欢迎页按钮立即消失。
- **重新扫描**：重新加载入口脚本，改完插件不用重启墨阅。
- **管理列表**：可按名称/作者/ID 搜索、按「全部 / 已启用 / 已停用 / 异常」筛选；卡片显示图标、版本、作者、元素/按钮/命令数量与加载失败原因；「详情」展开元素、按钮、命令、权限、入口与目录（桌面端可「在文件夹中显示」）。
- **格式栏入口**：桌面端每个启用插件在格式栏有一个自己的图标按钮，点开只列这个插件的元素、脚本按钮与命令；手机端收成一个「插件」下拉，按插件分组列出全部动作。
- **元素表单**：元素声明了字段（标题、内容、颜色、样式等）时，点选后先弹表单，确认后插入 `[name ...]`。
- **脚本按钮**：第一次运行会确认来源与脚本内容；之后不再询问。
- **菜单命令**：插件可以在「更多」菜单里加导入 / 导出 / 工具命令；导入类命令也会出现在欢迎页，所以没打开文档时也能导入。
- **信任模型**：插件是可执行本地代码，**墨阅不做沙箱**，只启用可信来源；`permissions` 只是声明字段，运行时不拦截。
- **Android**：插件同样通过 `.zip` 安装，存放在应用私有目录；没有「打开插件目录」与「在文件夹中显示」；入口脚本在渲染层执行，没有 `require`。详见 [插件制作指导](zh-Plugin-Authoring)。

## 12. 导入 Word 与导出 PDF

内置能力支持导出 PDF；示例插件 `moread-office` 增加了 Word 导入，并演示导出命令（桌面和 Android 通用）。

- **导入 Word**：「更多 → 导入 Word 文档…」或欢迎页的同一按钮 → 选择 `.docx` / `.docm` → 转换成 Markdown 并作为**新文档**打开。原文件与当前文档不受影响，需要保存时按 `Ctrl+S`。
  - 支持标题、粗体/斜体/删除线、等宽字体、列表、引用、简单表格；图片与脚注不导入，完成后会提示。
  - 旧版 `.doc` 不支持，会提示先在 Word 里另存为 `.docx`。
- **导出 PDF**：「更多 → 导出 PDF」（内置，或插件的「导出 PDF…」）。桌面端选择保存位置；Android 打开系统打印面板，可「另存为 PDF」。
- 插件未启用时，对应的导入/导出命令不会出现。

## 13. 导出与分享

- 导出 HTML / PDF / 纯文本：「更多」菜单。
- 分享：桌面把正文复制到剪贴板；Android 走系统分享面板（文件分享带 `.md` 文件名）。
- 导出的 HTML 是静态快照；插件元素按当前渲染结果导出，插件资源是 `file://` 绝对地址，换机器可能缺图。

## 14. 文件关联与命令行（桌面端）

- 「设置 → 默认打开方式」可把 `.md / .markdown / .mdown` 注册到墨阅（当前用户级别，不需要管理员）。
- Windows 10/11 可能需要在系统设置里再确认一次默认应用。
- 命令行：`moread 文档.md` 打开文件；`moread --import-theme="主题包.zip"` 启动时导入主题包。
- Android 没有命令行参数入口，也没有文件关联注册。

## 15. 设置

- 外观：主题（浅色 / 深色 / 跟随系统）、编辑器字号、自动换行。
- 编辑与阅读：同步滚动、自动保存。
- 默认打开方式：注册 / 打开系统默认应用设置。
- 插件管理：安装、启停、卸载、重扫（见 §11）。
- 快捷键与关于：查看快捷键表、版本号、打开配置目录。

## 16. Android 端差异

| 能力 | 桌面 | Android |
| --- | --- | --- |
| 打开 / 保存 | 原生对话框 | SAF；从别处打开多为只读，保存失败会引导「另存为」或写应用私有目录再分享 |
| 导出 PDF | 直接生成 | 系统打印面板 |
| 插件 | zip 安装 + 插件目录 | zip 安装到应用私有目录，无目录入口 |
| 图片插入 | 相对路径 | data URL（单张 ≤300 KB） |
| 主题包导入 | 拖入 / 工作室 / 命令行 | 工作室导入或系统「打开方式」 |
| 文件关联、窗口图标、拖拽、命令行 | ✅ | ❌ |

## 18. 常见问题

- **Windows 提示未知发布者**：安装包未签名，点「更多信息 → 仍要运行」。
- **中文乱码**：墨阅按 UTF-8 读写；请让外部程序也以 UTF-8 保存。
- **自动保存没有生效**：新文档先手动保存一次；「设置」里确认自动保存已开启。
- **主题/插件导入失败**：主题包需包含根目录的 `theme.json`，插件包需包含根目录（或唯一一级目录）的 `plugin.json`；列表或提示会给出原因。
- **插件命令没出现**：确认插件已启用；「更多」菜单在没有任何文档时整体禁用，但导入类命令可在欢迎页使用。
- **脚本按钮不能运行**：首次运行需要确认；被停用的插件不会显示按钮。
- **Android 找不到插件目录**：Android 版插件在应用私有目录，只能通过插件管理安装/卸载。
