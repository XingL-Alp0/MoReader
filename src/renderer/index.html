主页内容

用 Markdown 替换欢迎页的内容：可以放标题、说明、图片、链接和公式。留空或关闭时显示默认主页。

主页 Markdown

图片建议用「插入图片」添加：文件会复制到墨阅的主题资源目录，导出主题包时一起打包。也可直接写 https:// 图片地址。

效果预览

页面样式包

导入一份 CSS，直接作用在墨阅界面上。适合调整圆角、阴影、间距，或做一整套视觉风格。

CSS 内容

样式会插到页面最后，优先级高于内置样式。CSS 里引用图片请用绝对路径或 file:// 地址；受安全策略限制，@import 远程样式与远程字体会被拦截。

只导入可信来源的 CSS：样式可以隐藏按钮、遮挡界面。

软件图标

更换标题栏图标与当前窗口图标。任务栏固定图标由安装包资源决定。

当前图标 建议上传正方形 PNG / JPG / WebP，最大 1 MB。

贴纸

添加到界面上的装饰贴纸。添加后可直接拖动，双击贴纸删除。

自定义按钮

按钮会在右下角出现，点击时在当前窗口执行 JavaScript。只添加你信任的代码。

主题包库

导入的主题会保存到本地库，可以随时切换、修改后覆盖更新，或者删除。每个主题包的主页与图片各自独立存放。

当前主题

导出为 *.moread-theme.zip，内含 theme.json、style.css、home.md 和 assets/ 图片；也兼容导入旧版 .json 主题包。切换主题包只影响外观，不会改动任何文档。

分享建议
  • 先点「从主题色生成」得到整套组件颜色，再保存/导出，换机后效果一致。
  • 主页图片会复制到该主题包自己的资源目录，删除主题包时一并清理。
  • 自定义按钮的 JavaScript、CSS 样式都会包含在主题包里，导入陌生主题包前请确认来源可信。
