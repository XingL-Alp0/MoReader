# 示例插件 · 提示卡（moread-sample）

墨阅自带的插件示例，用来演示插件系统的两种能力：

- **Markdown 自定义元素**：在正文里写 `[note ...]`，预览中会渲染成一张提示卡。
- **脚本按钮**：在“主题工作室 → 按钮”或格式栏的提示卡插件图标里，快速插入提示卡或当前日期。

插件入口是 `index.js`，元数据是 `plugin.json`。

## 用法

在 Markdown 文档中插入：

```md
[note title="写作提示" content="先写完，再改好。"]
```

带颜色：

```md
[note title="注意" content="这一段需要复核。" color="#426b93"]
```

属性也可以不写引号（值里不能有空格）：

```md
[note title=提示 content=这是一条提示 color=#4f7d60]
```

插件启用后，桌面格式栏会多出一个属于本插件的提示卡图标（`assets/icon.svg`）：点开只列本插件的动作，既能插入提示卡元素，也能运行「插入提示卡」「插入日期」两个脚本，确认后再写入 `[note ...]`。手机端统一进「插件」下拉。

## 自定义

- 改 `plugin.json` 里的 `elements[0].html`、`css`、`defaults`，可以调整提示卡的结构和默认样式。
- 改 `buttons[].script`，可以改成任意合法的应用脚本，例如 `app.insert("...")`、`app.save()`。
- 修改后打开“设置 → 插件管理 → 重新扫描插件”即可生效。

## 安全

插件是本地代码，运行时可以调用应用提供的脚本 API。只安装和启用可信来源的插件。脚本按钮第一次运行时会弹出确认框并显示脚本内容。
插件目录位于应用目录或用户数据目录的 `plugins/`，用户目录中的同 ID 插件会覆盖应用自带的版本。

## 安装

把本目录打成 zip（`plugin.json` 放在压缩包根目录即可），在「设置 → 插件管理 → 安装插件（.zip）」选择它；也可以直接复制目录到 `plugins/`。安装后点「重新扫描插件」即可在文档里使用。
